# Prompt Catalog v0.4.3-draft

Status: DRAFT / DEC-036に基づくmock実装。出力品質と本人評価の検証前。

## 研究対象

主仮説と主対比を維持し、質問条件によってAIの創作を含む物語への記憶様感が異なるかを調べる。
質問、回答、創作、読後反応を含む処理全体の比較であり、AI利用自体や本人の記憶の正確性の比較ではない。
決定の正本は`../project/decisions.md` DEC-036。

## 質問生成

v0.4.2の本文とDEC-035の必須検証を継続する。
最終文章の創作許可を、参加者に記憶の推測を求める許可へ拡張しない。
全体のAPI版表示は`prompt-catalog-v0.4.3-mock-draft`とする。

## 文章生成

実行本文は`../../prompts/v0.4.3-mock-draft/narrative.ja.txt`。
全条件で同じ文章生成処理を使い、条件ラベルと評価値は渡さない。
初期断片と回答を素材として、情景、感覚、感情、行動、会話、出来事のつながりや結末を補える。
明示情報との矛盾は避け、非想起を本人による確かな想起と説明しない。
創作量の最低値は設けず、文の統合と語りの連続性を促す。

| 項目 | 値 |
|---|---|
| 入力 | `materials`: `fragment`と`answer-1`〜`answer-6`。`questionContext`: 質問と対応する`answerSourceId` |
| 長さ | 1〜10文。各`text`は完全な1文 |
| temperature | 0.75 |
| 生成回数 | 初回を含め最大3回。検査違反の理由を次回に渡す |
| 出力検査 | 型、文数、空文、重複、句点等の数、実験情報開示、素材IDの存在と重複、注釈の構造的整合 |
| 保存 | `data/results-v0.4.3.csv`の`narrative_annotations_json` |

出力例（形式の例であり実API出力ではない）:

```json
{
  "sentences": [
    {"text": "友人と公園を歩いた。", "sourceIds": ["fragment"], "containsCreativeAddition": false},
    {"text": "木漏れ日が足元で揺れていた。", "sourceIds": [], "containsCreativeAddition": true}
  ]
}
```

`sourceIds`は物語の素材の参照先であり、文全体が入力から直接導けることを保証しない。
素材を使いつつ創作も加えた文は、参照IDを付けたうえで`containsCreativeAddition: true`とする。
参照IDが空で追加申告がfalseの組合せは拒否する。
非想起表現を含む回答も素材として参照でき、部分的に想起された情報を一律に捨てない。
注釈はモデル自身の申告であり、創作を正確に検出する判定器ではない。

## 出力の評価

追加の存在そのものを不合格にしない。
入力との矛盾、読みやすさ、追加申告と実際の内容の対応、条件別の文章量と追加内容を別々に確認する。
DQ-UNSAIDは参加者が知覚した追加内容の診断であり、除外、再生成、主分析の共変量に用いない。
H1が有意になるかをプロンプトの採用基準にしない。
文別注釈を参加者の本文には出さず、創作を含むことは全条件共通の説明で伝える。
