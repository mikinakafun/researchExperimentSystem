# Prompt Catalog v0.4.2-draft

Status: 必須検証は継続。質問選択はDEC-039 / v0.4.4、最終文章はDEC-036 / v0.4.3、保存先はDEC-037で更新。以下はv0.4.2時点の記録。

v0.4.1では、自然な言い回しや参照回答に条件の指定語がないことでも生成質問を棄却していた。
v0.4.2では、必須検証を次の4種類に限定する。

| 必須検証 | 実装範囲 |
|---|---|
| 条件への適合 | 条件焦点メタデータの整合、明示的な条件外語彙の混入、Odorの発生源推測要求を検査する。条件を示す特定語の使用は要求しない |
| 実験情報の非開示 | 条件名、仮説、研究、実験、AI、プロンプトなどの開示を検出する |
| 出力形式 | JSON、空でない質問、フィールド型とenum、有効な証拠IDまたはnull、移行メタデータの整合を検査する |
| 重複 | 正規化後に過去の質問と一致する場合に拒否する |

文字数、疑問符数、接続語、顕著性表現、冒頭の定型、条件の必須語、証拠中の条件語、同じ証拠IDの再利用、ターン機能の順序、移行のターン番号は棄却条件にしない。
質問を簡潔にすることと、各ターンの機能は生成時の目安とする。
非想起の自動検出はプロンプトへの補助情報であり、部分的に想起された内容の参照まで禁止しない。
条件に合う対象がなければ、どのターンでも理由を記録して中立的な出来事質問へ移れる。

条件外語彙の検査には正規表現が残るが、特定の言い回しに適合させるためには使わない。
この検査だけで、意味的な条件適合、未報告事実の前提化、意味の近い重複を保証しない。
これらは生成指示と独立した出力評価で確認する。

実行時の本文は`prompts/v0.4.2-mock-draft/follow-up.ja.txt`と`follow-up-guidance.ja.txt`に置く。
文章生成はv0.4.1から変更せず、その実行ファイルを再利用する。
6ターン、質問temperature 0.55、最大3試行と固定フォールバックは維持する。
採用した質問のAPI応答には`source`と`attempts`があり、棄却履歴には質問本文とメタデータも含める。
保存先は`data/results-v0.4.2.csv`とし、従来の結果ファイルには追記しない。
