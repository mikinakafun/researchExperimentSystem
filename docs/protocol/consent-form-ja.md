# 研究参加に関する説明・同意文（日本語パイロット版）

- 版: 0.2.0-draft
- 状態: 指導教員・所属機関確認前
- 対応: DEC-019、DEC-020、DEC-027、DEC-033、DEC-036
- 適用: 日本語パイロット

## 研究の説明

この研究では、あなたが過去の一つの出来事について書いた短い記憶の断片と、その後の回答をもとに、コンピュータが短い文章を作成します。質問の仕方の違いが、作成された文章の感じ方にどのような違いをもたらすかを調べます。

AIは初期断片と回答を素材に物語を創作します。回答にない情景や感情、出来事が加わることがあります。生成文章は、実際の記憶を復元した記録ではありません。

実際の匂いを提示することはありません。質問の中で、出来事の行動・人物・順序、見た目の詳細、または匂いのいずれかに注意を向けます。匂いを思い出せない場合も、そのまま回答できます。

## 参加中に行うこと

1. 説明を読み、参加に同意します。
2. 少なくとも1週間前に起きた、特定の一回の出来事を一つ選びます。
3. 安全に説明できる出来事について、一文で記入します。日本語パイロットでは100文字以内を暫定上限とします。
4. 条件に応じた質問に6ターン回答します。思い出せない場合は「思い出せない」と回答できます。
5. 回答をもとに作成された文章を読み、4つの評価軸について回答します。
6. 質問がどの内容に注意を向けたか、回答がどの程度記憶に基づいていたかについて確認項目に回答します。

参加したくない場合や、途中で答えたくなくなった場合は、いつでも中止できます。思い出せない、または答えたくない場合は、別の出来事を一度だけ選び直せます。二回目も記入できない場合は、質問生成や外部API送信を行わずに終了します。

## 外部APIへの送信

記入した初期断片、質問への回答、および文章生成に必要な質問内容は、文章を作成するためにOpenAIのAPIへ送信されます。APIへ送信される内容には、あなた自身や他者を特定できる情報を入力しないでください。氏名、住所、電話番号、メールアドレス、学校名、勤務先などは記入しないでください。

OpenAIのAPIは研究者が管理する保存場所とは別のサービスです。研究者側で保存期間を管理しますが、API事業者側の処理・保持については、利用するAPI設定と事業者の規約に従います。標準API利用では、乱用監視のためにプロンプトや回答が最大30日保持される可能性があります。API側で保持された情報を研究者が個別に削除できない場合があります。

## 予想される負担・リスク

過去の出来事を思い出して書くことや、文章を読むことで、不快感、悲しさ、緊張、疲れなどを感じる可能性があります。つらい出来事や、説明することに不安を感じる出来事を選ぶ必要はありません。回答したくない内容は回答せず、いつでも中止してください。

この研究への参加によって、あなたに直接の利益が生じるとは限りません。

## データの保存と利用

研究者は、研究の実施状況と結果を確認するため、次の情報を保存します。

- 研究用のセッションID、プロトコルの版、条件、開始・終了時刻、状態
- 同意結果と同意文の版
- 初期断片、質問、回答、回答の状態、ターン番号
- 文章生成の記録（モデル、プロンプト版、生成時刻、試行結果など）
- 作成された文章、文ごとの素材参照とAIによる追加の自己申告、4つの評価軸への回答、確認項目への回答、割付記録

氏名などの直接的な識別情報は収集しません。ただし、自由記述の内容から本人や他者が推測される可能性を完全になくすことはできません。研究結果を発表する場合は、個人が特定されない集計値または十分に加工した内容を使用し、初期断片・自由記述・作成文章をそのまま公開しません。

研究成果の根拠となるデジタル研究資料は、最終成果の公表日から10年間保存します。公表しないパイロットの場合は、研究終了報告日から10年間保存します。所属機関の規程、法令、契約または同意文により、より長い保存期間が必要な場合は、その規定に従います。

## 参加の撤回と削除

参加は任意です。参加しない場合や途中で撤回した場合に、不利益を受けることはありません。

匿名化または集計前であれば、研究用セッションIDをもとに、あなたに関連する初期断片、回答、生成記録、作成文章、評価回答、確認項目、割付記録を削除します。削除を希望する場合は、下記の連絡先へセッションIDを伝えてください。

匿名化または集計が完了した後は、個人と結び付けられないため、あなたのデータだけを特定して削除できない場合があります。外部API事業者側に保持されたログについては、研究者が個別削除できない場合があります。この点を理解したうえで参加してください。

## 研究結果の利用

研究結果は、卒業研究、学会発表、研究報告書、論文などで利用する可能性があります。利用する場合は、個人が特定されない形で扱います。研究目的以外の目的で、あなたの回答を使用しません。
