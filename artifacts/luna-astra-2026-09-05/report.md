# Luna実行・Astra分析：出力は変わったが、改善と心理的効果は別判定

今回の合成30例では、旧版より全30文章が短くなった。平均286.7字→185.1字、35.4%減である。現行のOdorはVisualより匂い描写が多い一方、文章量は平均25.1字少なく、10ペルソナ中7例で短かった。これは観測した出力の差であり、本人の記憶様感が変わった証拠ではない。確信度は、このデータ内の数値について高、他の入力・再生成への一般化について未判定。原CSVとAPI原応答から再計算して一致しない場合、数値の結論は反証される。

品質の一律な改善は確認できない。非想起表現を含む回答は旧42/180→現103/180、固定質問への切り替えは6/180→14/180へ増えた。匂いを思い出せない設定の図書館・美術館では、現行でも6問連続で匂いを尋ねた。創作そのものは現行仕様で許可されるが、追加した内容を「追加なし」と申告する例も残る。確信度は、具体例の存在について高、全体の改善・悪化の因果判断について低。異なる原応答が正しい保存結果である場合、または独立再評価で引用箇所が素材に明示されていたと確認された場合、該当する批判は反証される。

優先する変更は次の順序とする。システムの修正・追加API実行は今回行っていない。

1. **非想起後の切替を先に直す。** 匂い情報が一切得られない図書館・美術館の入力を具体的な回帰例にし、生成器の`nonRecallTransition`自己申告だけで成功判定しない。反証条件は、同じ非想起履歴で条件内の新情報に基づく質問、または適切な中立質問へ実際に切り替わること。
2. **意味上の焦点のずれを直す。** Standardの風景質問と、Odorの「行動に与えた影響」「別の場面の連想」を区別して確認する。正規表現に通ることを適合の根拠にしない。反証条件は、今回の引用例が現行の操作定義に適合すると独立に判断できること。
3. **模擬回答と創作申告を別に検証する。** 匂い→集中力のような設定外回答を、実験効果へ読み替えない。素材を固定した再試験と独立読解で、質問の効果と模擬回答器の作話を分ける。創作量の比較には自己申告誤りの点検が先に必要。
4. **心理的効果は本人の評定で判定する。** 今回そろったのは出力の動作検証である。既存の研究上の確認を経た人間パイロットで、記憶様感と操作確認を測定する。大きな追加合成バッチだけでは、この未測定部分は埋まらない。
