# Luna実行・Astra分析：実行結果を見る前の分析方針

2026-09-05。ユーザーの実API実行依頼に基づく合成データ検証。公開事前登録ではなく、今回の分析手順の固定記録。

1. 実行担当はGPT-5.6 Luna、分析担当はGPT-6 Astra。実験APIの生成モデル・プロンプトは現行設定を維持する。LunaとAstraの生成能力比較ではない。
2. 日本語、固定合成ペルソナ10件×Standard / Visual / Odorの30セッション。各6問と模擬回答、最終文章。本人の評定は作らない。
3. 主な診断は現行Odor対Visual、補助比較はOdor対StandardとVisual対Standard。同一ペルソナを対応させ、セッションを集計単位とする。180問を180人とは扱わない。
4. 記述指標：質問・回答・文章の文字数、匂い語の言及、非想起回答、フォールバック・再試行、創作追加の自己申告、匂い非想起ペルソナの挙動。語彙一致は意味的な条件適合や記憶の指標とは呼ばない。
5. Astraが原文を読んで質問焦点、非想起後の扱い、入力との矛盾、創作追加申告の不一致を確認する。素材にない追加と素材との矛盾を分け、追加自体を現行仕様違反にしない。生成器のメタデータを独立評価の代用にしない。
6. 歴史的比較はdata/results.csvのbatch-20260725-prompt-evalの30件に限定。旧non-odorと現Visual、旧odor-basedと現Odorを対応表示するが、条件定義と創作方針が変更されているため、同一条件の厳密な前後試験とは扱わない。固定回答版・人間データ・保存疎通fixtureは混ぜない。
7. 主な出力には対応差の平均・方向の一致数を示す。固定した10例、各条件1生成であり、母集団への有意差や反復再現性は主張しない。歴史的な差を特定変更の因果効果とは解釈しない。
8. 各主要結論に確信度、反証条件、原文引用・ローカルファイル参照・分析コメントを付ける。H1（本人の記憶様感の条件差）は今回の合成生成だけでは未検証。

評価対象の定義の根拠：original_text — 「主要評価軸: 記憶様感（Perceived Memory-Likeness）」／source — docs/protocol/PROTOCOL.md、§1／note — 文章の文字数や匂い語率の差を主要評価軸の差に置き換えない。
